# 导入格式

所有文本输入保存为 UTF-8。目标 Vault 必须是已经存在的文件夹。命令中的脚本路径以实际安装位置为准。

| 输入 | 参数 | 能生成什么 |
| --- | --- | --- |
| 粘贴自小红书的分享文案或链接 | --format shares | 标题、原帖链接、可选收藏夹。每行一条分享文案最好 |
| 自己整理的 JSON 清单与本地文件 | --format json | 笔记、作者、标签、收藏夹，以及可播放或查看的本地附件 |
| RedNote Vault Sync 旧笔记 | --format legacy | 从旧 Markdown 读取正文和原帖信息，复制它引用的本地图片和视频 |

## JSON 清单

JSON 文件必须是 {"version": 1, "items": [...]}。每条记录需有 url 或 24 位十六进制 id，其余字段均可省略。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| url | 字符串 | 小红书原帖或分享短链。保留链接主体，丢弃查询参数和片段 |
| id | 字符串 | 已知的笔记 ID。和直链同时给出时必须一致。和短链同时给出时按 ID 去重 |
| title、author、collection、body | 字符串 | 标题、原作者、收藏夹和正文 |
| tags | 字符串数组 | 例如 ["空间", "设计/灯光"]。含空格和 Obsidian 不接受的标点会被跳过 |
| media | 字符串数组 | 相对 JSON 文件所在目录的本地文件名，例如 ["media/灯光.png"] |

图片支持 JPG、PNG、GIF、WebP、AVIF、BMP。视频支持 MKV、MOV、MP4、OGV、WebM，能否播放取决于设备编解码器，见 [Obsidian 支持的文件格式](https://obsidian.md/help/file-formats)。附件需要是非空的本地文件，缺失时该条报错，修正后可以重试。正文按文本导入，附件单独通过 media 声明。

## 旧库迁移

用 --legacy-vault 指定旧库根目录，--source 指定其中的单篇 Markdown 或旧收藏子目录。可导入同一个 Vault 下的另一个目录，只要输出目录不在扫描范围内。

脚本识别 sourcePlugin: rednote-vault-sync、sourcePlatform: rednote 和 sourceId 属性，跳过媒体索引页。它读取旧版 Vault 相对的 ![[媒体路径]]，也支持旧笔记旁的本地媒体。它复制支持的图片和视频，统计旧笔记中的远程图片链接，并以文本保留不支持的本地嵌入。请保留旧 Vault 的原始目录结构。旧库的账户字段、其他自定义属性和插件设置不迁移。

## 去重、文件和报告

- 笔记固定保存到 <输出目录>/笔记/<ID>.md。标题在笔记属性和正文中，也作为 Obsidian 别名。重复导入会跳过同一路径的既有笔记并保留修改。已有链接索引时，导入更完整的同一篇笔记可另选 --folder。混合来源按含正文和附件的版本优先。
- 同一笔记内按内容哈希复用本地附件。导入先写附件，再写 Markdown。若被中断，重复运行会复用校验一致的附件。
- 直链以笔记 ID 去重。短链在离线模式下以短链本身去重，无法判断它和某个直链是否是同一篇帖子。少数需要额外访问参数的原帖链接可能要在小红书里重新打开。
- --dry-run 只读输入，给出计划导入的笔记和附件数量。输出为 JSON，input 是输入行号、JSON 数组中的一基序号或旧笔记候选文件的一基序号。
- 返回码 0 表示没有失败记录，1 表示有单条失败且其他条目继续处理，2 表示命令或整个输入无效。报错时先读 reason 或 error。
