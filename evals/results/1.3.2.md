# v1.3.2 定向复测

三条样本由用户在 iPhone 上从小红书复制。仓库中的 [shares_device.txt](../../tests/fixtures/shares_device.txt) 替换了标题、摘要和短链标识，保留 `xhslink.cn/o/`、单行结构、标点、表情和三种分享提示。测试不访问分享链接。

另有三条从电脑网页版复制的原帖直链。 [shares_web.txt](../../tests/fixtures/shares_web.txt) 替换了笔记 ID 和 token 值，保留参数名和值的格式。回归分别验证纯 URL 和在聊天中收到的 Markdown 链接形式。本版样本覆盖 iPhone 与电脑网页，Android 未实测。

| 验收 | 结果 |
| --- | --- |
| v1.3.1 短链兼容性 | 分享文件和收件箱均拒绝三条 `xhslink.cn/o/` 样本。 |
| v1.3.2 分享文件 | 新建三篇，保留分享标题、短链和稳定的短链 ID。原样重跑识别为三篇已有笔记，新增零篇。 |
| v1.3.2 收件箱 | 新建三篇，三条成功记录移入「已处理」。重跑新增零篇。 |
| 电脑网页分享 | 纯 URL 归档三篇。修复前 Markdown 形式会多报三条重复记录，修复后每条只计一次。归档链接去除查询参数，重跑新增零篇。 |
| v1.3.1 正式包的桌面显示 | macOS Obsidian 1.15.0 中，「未导入」独立显示为提示框，下一条分享在框外。「整理」在「我的笔记」之前。「全部」「按收藏夹」「未读」均可打开并显示演示笔记。 |

本机 Python 3.9.6 运行完整 pytest 套件，55 项通过。宿主行为评估沿用 [v1.3.1 报告](1.3.1.md)，本轮仅做上述定向复测。
