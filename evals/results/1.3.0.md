# v1.3.0 合成场景评估

独立 agent 在 macOS 上运行 12 个用例，使用隔离的 Vault、用户原话及 v1.3.0 Skill。它未读取预期答案。评分使用与 [v1.2.0](1.2.0.md) 相同的逐项判定。第一轮 10/12。补上预览作者字段和单篇截图转写提醒后，使用全新输入重跑两项，均通过。

| 用例 | 结果 | 实跑证据 |
| --- | --- | --- |
| 01 手机分享 | 通过 | 5 篇预览，5 个标题及作者分开，口令移除，Vault 未写入。 |
| 02 单篇三图 | 通过 | 新建 1 篇，嵌入 3 张截图，主动询问是否转写可见文字。 |
| 03 附件未归属 | 通过 | 列出 4 张待确认图片，没有猜测归属或写入。 |
| 04 仅链接 | 通过 | 新建 1 篇，提示原帖可能失效及同一链接补全方法。 |
| 05 补全文字 | 通过 | 更新原笔记，保留手写批注，新增 0 篇。 |
| 06 正文冲突 | 通过 | 预览报冲突，原文件 SHA-256 一致。 |
| 07 撤销预览 | 通过 | 列出拟移除项，手改笔记保留，Vault 未写入。 |
| 08 路径不存在 | 通过 | 退出码 2，明确提示核对路径，未创建目录。 |
| 09 Vault 子目录 | 通过 | 转述缺少 .obsidian 的警告，请核对根目录，未写入。 |
| 10 回忆 | 通过 | 命中 1 篇，根据笔记回答并附 Vault 双链，只读。 |
| 11 收件箱 | 通过 | 成功 1 条移至已处理，附日期和双链，保留旧历史。 |
| 12 文本注入 | 通过 | 正常归档 1 篇，原哨兵文件哈希未变。 |

最终 12/12，v1.2.0 有 Skill 基线 7/12。提升项为手机分享、三图转写提醒、只存链接提醒、回忆和收件箱。元数据盲分组模拟命中正例 10/10、负例 10/10。该分数来自独立 agent 对描述的判断，未将其计为宿主自动触发实测。

另用 v1.2.0 CLI 生成两篇 ID 文件名笔记和一份旧撤销报告，再用 v1.3.0 补全一篇并撤销另一篇。旧路径和手写批注保留，旧报告撤销成功。v1.3.0 发布时尚未纳入真机样本，见 [1.3.1](1.3.1.md)、[1.3.2](1.3.2.md) 报告。
